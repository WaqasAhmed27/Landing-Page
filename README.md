# TapTile Landing Page 🧾✨

The official landing page for **TapTile** — Pakistan's first digital receipt infrastructure. 
This project showcases a bold, neo-brutalist design built to highlight TapTile's revolutionary plug-and-play middleware that transforms the traditional POS experience into a 100% paperless, NFC-enabled digital receipt ecosystem.

## 🚀 Features

- **Neo-Brutalist Design**: High-contrast, vibrant colors, stark borders, and bold typography for a modern, engaging user experience.
- **Interactive Calculator**: A dynamic ROI calculator for retailers to see the environmental impact (water preserved, paper saved, trees shielded) and roll expenses saved based on their daily transaction volume.
- **Scroll Animations & Effects**: Smooth scroll progress indicators, marquee texts, sticky sections, and Easter eggs (like a hidden trail canvas triggered by clicking the logo 5 times).
- **Responsive & Mobile-First**: Flawlessly adapts to any screen size, ensuring a premium browsing experience on both desktop and mobile devices.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Bundler**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: Custom CSS animations + [Motion](https://motion.dev/)
- **Language**: TypeScript

## 📦 Getting Started

### Prerequisites

Ensure you have **Node.js** (v18 or higher recommended) installed on your machine.

### Installation

1. Install the dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open your browser and visit the local port (usually `http://localhost:3000` or `http://localhost:5173`) to view the app.

## 🏗️ Build for Production

To build the project for production, run:

```bash
npm run build
```

This will generate an optimized bundle in the `dist` folder. To preview the production build locally, run:

```bash
npm run preview
```

## 🌍 About TapTile

TapTile intercepts standard ESC/POS print jobs from any billing software and generates a digital receipt in parallel. With a dedicated counter device, customers can simply tap their phone via NFC (or scan a QR code) to receive their receipt in under 2 seconds—no app required, no POS integration needed, completely offline-capable at the counter.
